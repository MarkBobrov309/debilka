# ADR 0001: Разделение управления и передачи трафика

Status: Accepted · 2026-09-28

## Context
Нужно централизованное управление распределённой инфраструктурой с различными
VPN и transport engine, позднее — multi-hop и failover.

## Decision
Go Controller управляет доменными сущностями и Desired State. Независимый Go Agent
исполняет локальные операции и сообщает Actual State. Пользовательский трафик
передаётся между Data Plane узлами. REST — внешний API, защищённый gRPC — будущий
канал Controller ↔ Agent. Xray подключается через transport adapter.

## Alternatives
Редактирование xray.json через SSH не даёт независимой модели состояния и
безопасного deployment. Центральный транзитный VPN создаёт обязательную точку
передачи трафика. Единый provider ограничивает расширяемость.

## Consequences
Нужны reconciliation, версионирование и проверка результатов. Их реализация
отложена до соответствующих фаз. Недоступность Controller не должна сама по себе
останавливать уже настроенный Data Plane; детали политик определяются позже.
